# 代码动画风格提示词

一共 **341 种**风格，每种一个提示词，Opus 5.5 能用，DeepSeek 也能用。其中 193 种带静帧。

有一些是从网上收集来的，很多是我自己整理、自己做出来、自己总结的。

## 里面有什么

| 文件夹 / 文件 | 是什么 |
|---|---|
| `风格挑选.html` | 挑选网页。用 Chrome 或 Edge 直接双击打开，不用联网。可以按类别筛、搜索、放大看静帧、看提示词、勾选、导出清单。不要把它和"风格提示词"文件夹分开。 |
| `风格提示词/` | 341 种风格，每种一个 `.md` 提示词，带静帧的旁边有一张同名 `.jpg` |
| `示例/` | 两组实测：同一份详细提示词交给 Opus 5.5 和 DeepSeek 的对比；只给一句话交给 DeepSeek 的结果 |
| `许可与来源.md`、`第三方许可/` | 每一类风格从哪来、用什么许可 |

## 怎么用

**用 DeepSeek Harness（或 Claude Code）：**

1. 把这个文件夹放到它能读到的地方，跟它说："读一下这个文件夹，我要用里面的风格做代码动画。"
2. 在 `风格挑选.html` 里挑好风格，点"已选清单"复制，发给它。
3. 讲清楚你想表达什么：讲什么内容、多长、横屏还是竖屏、镜头怎么走、几种风格怎么接在一起。
4. **记得说要不要配乐和音效。**不说的话，它多半做出来是没声音的。
5. 让它输出一个能在浏览器里打开的 html，再让它渲成视频。

**直接用一个风格：**打开那一种的 `.md`，把"风格提示词"那一段复制给模型，再加上你的内容。有些提示词里有 `{{ }}`，那是要你自己填的地方。

**小提示：**提示词写得越细（颜色、时间、镜头都写死），不同模型做出来越接近；只给一句话也能做，但每次结果都不一样，也更慢。`示例/` 里两种都有。
